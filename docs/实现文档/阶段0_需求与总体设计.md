# 阶段 0：需求与总体设计 · 实现技术文档

## 1. 阶段目标

冻结需求范围与技术方案，输出一份**全组对齐的接口契约**。本阶段不写业务代码，目标是让后续所有阶段"照着接口做，不需要反复开会确认"。

## 2. 前置条件与依赖

- 无前置代码依赖。仅需需求评审通过、技术选型已初步确定（见总览文档二、2.3 节）。

## 3. 工作分解（WBS）

1. 需求清单定稿（MoSCoW 四象限）。
2. 总体架构定稿（四层：展示 / 应用 / 算法 / 数据）。
3. 定义统一检测结果数据结构 `Detection`。
4. 定义算法统一接口 `Detector`（抽象基类）。
5. 定义输入源统一接口 `InputSource`（抽象基类）。
6. 定义处理流水线各环节边界（采集→预处理→检测→后处理→标注/判定→存储/报告）。
7. 制定验收标准与里程碑细则。

## 4. 关键技术决策

| 决策点 | 结论 | 理由 |
| --- | --- | --- |
| 算法接入方式 | 抽象基类 + 注册/工厂模式 | 新增算法不改主流程，实现"可替换" |
| 结果结构 | 单一 `Detection` 数据类统一阵营 | 传统算法与 YOLO 输出同构 |
| 面积口径 | 像素面积 + 相对图像占比双口径 | 兼容不同分辨率输入 |
| 置信度口径 | 0.0–1.0 浮点 | 统一；UI 层再换算百分比 |
| 输入体系 | 图片/视频/摄像头统一输出帧 | 三种来源共用一条处理管线 |

## 5. 接口契约（本阶段核心交付，需冻结）

### 5.1 `Detection`（检测结果）

需包含字段（字段名与类型全组统一）：

- `class_id` / `class_name`：缺陷类别。
- `bbox`：边界框 `(x, y, w, h)`，坐标系与原点全组统一。
- `mask`：可选，分割掩码（像素级）。
- `area_px`：像素面积（int）。
- `area_ratio`：相对图像面积占比（float）。
- `confidence`：置信度 0.0–1.0。
- `severity`：可选，严重度等级（阶段 6 扩展，此处预留）。

字段约定：

- `class_id`：int，类别标识；`class_name`：str，与 class_id 一一对应。映射表在阶段 3 首次定义时写死，阶段 4 必须复用同一张表，不得各自定义。
- `bbox`：像素 int `(x, y, w, h)`，原点左上、x 向右、y 向下，`(x,y)` 为框左上角，不使用归一化坐标。
- `area_px`：int，缺陷实际像素面积，不等于 bbox 矩形面积（细长划痕的 bbox 面积可能远大于实际像素面积）。
- `area_ratio`：float，0~1，缺陷面积 / 图像面积。
- `confidence`：float，0.0–1.0；传统算法可用规则分数近似，不得为 None。
- `area_px` / `area_ratio` / `confidence` 均不可为 None；算不出说明该检测结果无效，不应输出。

### 5.2 `Detector`（检测器抽象）

- `load(cfg)`：加载/初始化算法。
- `detect(frame) -> List[Detection]`：核心方法，所有算法必须实现，**签名不可变**。
- `name` / `version`：算法标识，供界面与报告溯源。
- `release()`：释放资源（GPU 显存、模型句柄）。

方法契约补充：

- `load(cfg)`：cfg: dict，字段 TBD-阶段 2；返回 None；加载失败抛 DetectorLoadError，由调用方捕获。
- `detect(frame)`：frame: Frame（帧对象）；返回 List[Detection]；无缺陷返回空列表 []，不返回 None；输入非法抛 ValueError，内部推理异常抛 DetectorInferenceError。
- `name` / `version`：均为 str，不可 None；version 格式 TBD-阶段 1。
- `release()`：返回 None；应幂等——重复调用不抛异常、不重复释放；实现细节 TBD-阶段 2。

### 5.3 `InputSource`（输入源抽象）

- `open(source_cfg)`：source_cfg: dict，字段 TBD-阶段 2；返回 None；打开失败抛 SourceOpenError，由调用方捕获。
- `read()`：返回 Frame 或 None；None 只表示读尽/结束，出错抛 InputSourceError；同一返回值不得同时表示「读尽」与「出错」。
- `close()`：返回 None；应幂等；实现细节 TBD-阶段 2。

帧对象字段（冻结）：

| 字段 | 类型 | 单位/口径 |
| --- | --- | --- |
| image | np.ndarray，uint8，H×W×3，BGR 通道 | 需 RGB 的算法在检测器内部自行转换，帧对象本身不改 |
| width | int | 像素，对应 image.shape[1] |
| height | int | 像素，对应 image.shape[0] |
| frame_index | int | 从 0 起的源帧序号；跳帧时仍为源帧号 |
| timestamp | float | 秒，从源起点算；图片为 0.0 |

帧对象字段冻结；后续阶段只允许新增可选字段，不允许改已有字段名、类型、单位。
